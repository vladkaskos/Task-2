# Face Access System — PoC

PoC демонстрирует систему прохода по лицу с тремя решениями: `allow`, `manual_review`, `deny`. Сомнительные случаи автоматически не открывают турникет.

## Запуск

```bash
python poc/ui.py
```

Проверка:

```bash
python poc/test_smoke.py
```

## Что реализовано

Есть простой интерфейс на **Tkinter**, логика принятия решения, audit log и 5 demo-сценариев: обычный проход, плохой кадр, spoofing, неоднозначное совпадение и offline-режим.

CV-компоненты: реальные биометрические данные, модели распознавания и интеграция с турникетом не используются.

## Ценность

Система должна сократить очереди, уменьшить нагрузку на охрану и снизить риск передачи пропусков. Оценочный эффект первого года — около **11,6 млн ₽**.

## Ограничения

Перед реальным запуском нужны тесты качества распознавания, anti-spoofing, отказоустойчивости и безопасности биометрических данных.
